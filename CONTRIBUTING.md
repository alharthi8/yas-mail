# Contributing

Thank you for helping improve Yas Mail. This is an early Windows preview.

Start with the README and preview limitations. Open an issue describing the problem, operating-system/app version, expected behavior, and steps to reproduce. Use sample accounts and redact personal messages, tokens, passwords, and browsing data.

For changes, open a focused pull request with a description and relevant test results. Keep the existing Yas branding consistent. macOS work needs platform-specific testing. Changes are contributed under the repository's MIT license; third-party components retain their own licenses.

Resource-use claims must include a repeatable workload and all renderer processes. Avoid unsupported speed or memory percentages.
